# Computer Networks Project 1: LAN Topology

## 📌 Project Overview
This project demonstrates a Local Area Network (LAN) using Cisco Packet Tracer. Four computers are connected to a single switch to enable communication within the same network.

## 🎯 Objective
To create a simple LAN topology and verify connectivity between computers using the `ping` command.

## 🛠️ Tools Used
- Cisco Packet Tracer
- PCs and a Network Switch

## 🖥️ Network Topology
- 4 PCs
- 1 Switch
- Copper Straight-Through cables

## 🌐 IP Address Configuration

| Device | IP Address | Subnet Mask |
|---|---|---|
| PC0 | 192.168.1.1 | 255.255.255.0 |
| PC1 | 192.168.1.2 | 255.255.255.0 |
| PC2 | 192.168.1.3 | 255.255.255.0 |
| PC3 | 192.168.1.4 | 255.255.255.0 |

## ⚙️ Steps to Implement
1. Add four PCs and one switch in Cisco Packet Tracer.
2. Connect each PC to the switch using Copper Straight-Through cables.
3. Configure the IP addresses and subnet masks.
4. Open Command Prompt on a PC.
5. Use the `ping` command to test connectivity between PCs.

## ✅ Expected Result
All four PCs can communicate with each other within the same LAN. Successful ping replies confirm network connectivity.

## 📚 Conclusion
This project demonstrates basic LAN setup, IP addressing, and connectivity testing using Cisco Packet Tracer.
